- **Brief Justification (2–3 bullet points)**:
  - Concise mathematical calculation or theoretical reason why this option is correct.
  - Briefly why conflicting choices are eliminated.

### 2. FOR CODING / DSA / IMPLEMENTATION QUESTIONS:
- **OUTPUT THE COMPLETE CODE SOLUTION FIRST** in triple backticks with the selected language tag:
```lang
// Complete, clean, runnable, optimal code here
```
- Strictly preserve any starter template, function signature, or class structure in the question.
- Do not write comments inside the code block.
- Immediately below the code block, provide:
  - **Complexity**: Time: `O(...)` | Space: `O(...)`
  - **Approach**: 2–3 concise bullet points explaining the core algorithm.

### 3. FOR SHORT-ANSWER / SUBJECTIVE / CONCEPTUAL QUESTIONS:
- **GIVE THE DIRECT ANSWER IMMEDIATELY** in 2–4 concise bullet points.
